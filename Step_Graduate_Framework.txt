Chapter 2: Native Z6 Phase Space

2.2 The Probability Simplex and Coherence Observable
Let the state distribution reside on the 5-simplex (an array of 6 non-negative probabilities that sum exactly to 1).
We define the Gem Coherence Observable (G) as the first circular moment of the distribution:
G(p) = sum(p_j * zeta^j) for j = 0 to 5
From G, we extract two primary macro-observables:

 * Directional Phase Angle (theta = arg(G)): Measures net phase orientation. (Undefined when G = 0).

Chapter 4: Circulant Chirality-Viscosity Dynamics
4.1 Transition Operator Definition
System evolution over discrete time steps t is governed by a stochastic circulant transition matrix Q, parameterized by viscosity (v in [0, 1], representing state retention) and chirality (c in [-1, 1], representing directional bias):
For any state j, transitioning to state k:
Q(j, k) = v, if k = j
Q(j, k) = (1 - v) * (1 + c) / 2, if k = (j + 1) mod 6
Q(j, k) = (1 - v) * (1 - c) / 2, if k = (j - 1) mod 6
Q(j, k) = 0, otherwise.
This operator satisfies nonnegativity, row normalization, and total probability conservation.
4.2 The First-Mode Eigenvalue Theorem & Proof
The macroscopic coherence evolves under the row-vector convention according to the exact analytical eigenvalue lambda.
Setting:
a = (1 - v) * (1 + c) / 2
b = (1 - v) * (1 - c) / 2
Using the row-vector convention and cyclic indices, we evaluate G(p * Q):
G(p * Q) = sum( p_j * (v * zeta^j + a * zeta^(j+1) + b * zeta^(j-1)) )
= (v + a * zeta + b * zeta^-1) * G(p)
= [ (1 + v) / 2 + i * (sqrt(3) / 2) * (1 - v) * c ] * G(p)
Iteration proves the central theorem for the first Fourier mode:
G(p * Q^t) = G(p) * lambda^t, for t >= 0
4.3 Behavioral Qualifications
The magnitude of the eigenvalue is bounded:
|lambda|^2 = [ (1 + v)^2 + 3 * (1 - v)^2 * c^2 ] / 4 <= 1
Equality occurs solely when v = 1 (no movement) or v = 0 and c = +/-1 (deterministic rotation). Elsewhere, |lambda| < 1.
Therefore, strictly bounded geometric decay (rho_t = rho_0 * |lambda|^t) occurs when |lambda| < 1 and rho_0 > 0. The angle formula (theta_t = theta_0 + t * arg(lambda) mod 360) requires G_0 != 0; furthermore, with negative chirality, the angle decreases rather than advances positively when v < 1 (at v = 1, the system does not rotate regardless of chirality).
Chapter 5: Step Logic Ledgers vs. Ensemble Probabilities
5.1 Dual-Layer Architecture
The Step Graduate Framework explicitly maintains two parallel layers:
 * The Probabilistic Ensemble (p_t): Evolving under the Markov transition operator Q.
 * The Deterministic Step Logic Ledger (L_t): Maintaining an explicit, unwrapped path record.
5.2 Ledger Formalization
The ledger does not represent every stochastic path contributing to the ensemble distribution; rather, it tracks an independent reference trajectory:
 * Resolved modular state: chi_t = (chi_0 + k_t) mod 6
 * Unwrapped cumulative offset: k_t = sum(delta_r) from r = 1 to t
 * Complete path record: L_t = (chi_0; delta_1, ..., delta_t; k_t, chi_t)
The stored sequence of cumulative offsets permits exact reconstruction of distinct increments at any time step through the relation:
delta_t = k_t - k_(t-1)
Chapter 6: Computational Verification
The following verification baseline script implements dimensional and numerical safeguards. It demonstrates machine-precision agreement between direct matrix evolution and the analytical formula during the reported eight-step baseline run. import numpy as np

class GemPrismEngine:
    def __init__(self, p_initial, v=0.8, c=0.0, tol=1e-12):
        """
        Initializes the Z6 Step Graduate Framework Engine with input validation.
        """
        if not np.isfinite(tol) or tol <= 0:
            raise ValueError("tol must be finite and positive.")
            
        self.tol = tol
        p_arr = np.array(p_initial, dtype=float)
        
        # Rigorous Probability and Parameter Safeguards
        if p_arr.shape != (6,):
            raise ValueError("Probability vector must have exactly 6 elements.")
        if not np.all(np.isfinite(p_arr)):
            raise ValueError("Probability entries must be finite.")
        if np.any(p_arr < 0) or not np.isclose(np.sum(p_arr), 1.0, atol=self.tol, rtol=0.0):
            raise ValueError("Probability vector must sum to 1.0 and contain non-negative values.")
        if not (0.0 <= v <= 1.0):
            raise ValueError("Viscosity v must be within [0.0, 1.0].")
        if not (-1.0 <= c <= 1.0):
            raise ValueError("Chirality c must be within [-1.0, 1.0].")

        self.p = p_arr
        self.v = v
        self.c = c
        
        # Z6 phase roots: exp(i * pi * j / 3)
        self.j_vals = np.arange(6)
        self.zeta = np.exp(1j * np.pi * self.j_vals / 3.0)
        
        # Build transition matrix Q
        self.Q = self._build_transition_matrix()
        
        # Step Logic History Ledger tracking (independent reference path)
        self.base_state = 1
        self.cumulative_offset = 0
        self.history_ledger = [(self.base_state, self.cumulative_offset, self.base_state)]

    def _build_transition_matrix(self):
        Q = np.zeros((6, 6), dtype=float)
        for j in range(6):
            Q[j, j] = self.v
            Q[j, (j + 1) % 6] = (1.0 - self.v) * (1.0 + self.c) / 2.0
            Q[j, (j - 1) % 6] = (1.0 - self.v) * (1.0 - self.c) / 2.0
        return Q

    def compute_coherence(self):
        """Calculates the Gem Coherence vector G = sum(p_j * zeta^j)."""
        G = np.sum(self.p * self.zeta)
        rho = np.abs(G)
        
        # Numerically unresolved phase safeguard
        if rho < self.tol:
            theta_deg = np.nan
        else:
            theta_rad = np.angle(G)
            theta_deg = np.degrees(theta_rad) % 360
            
        return G, rho, theta_deg

    def analytical_eigenvalue(self):
        """Computes the exact analytical eigenvalue lambda."""
        real_part = (1.0 + self.v) / 2.0
        imag_part = (np.sqrt(3.0) / 2.0) * (1.0 - self.v) * self.c
        return complex(real_part, imag_part)

    def step(self, delta_k=1):
        """Evolves the distribution and updates the reference ledger."""
        if not isinstance(delta_k, int):
            raise ValueError("delta_k must be an integer to retain discrete ledger boundaries.")
            
        self.p = self.p @ self.Q
        self.cumulative_offset += delta_k
        current_state = (self.base_state + self.cumulative_offset) % 6
        self.history_ledger.append((self.base_state, self.cumulative_offset, current_state))
        return current_state

    def run_simulation(self, steps=8):
        if not isinstance(steps, int) or steps < 0:
            raise ValueError("Steps must be a non-negative integer.")
            
        print(f"--- Running Simulation (Viscosity v={self.v}, Chirality c={self.c}) ---")
        G_0, rho_0, theta_0 = self.compute_coherence()
        print(f"Step 0  |  |G| = {rho_0:.4f}  |  Arg(G) = {theta_0:6.2f} deg  |  G = {G_0}")
        
        lam = self.analytical_eigenvalue()
        
        for t in range(1, steps + 1):
            self.step(delta_k=1)
            G_t, rho_t, theta_t = self.compute_coherence()
            G_predicted = G_0 * (lam ** t)
            print(f"Step {t:2d} |  |G| = {rho_t:.4f}  |  Arg(G) = {theta_t:6.2f} deg  |  Matrix vs Analytic Diff: {abs(G_t - G_predicted):.2e}")
